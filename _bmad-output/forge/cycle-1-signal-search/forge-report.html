Cycle 1 signal search

Test whether explicit feature agreement improves the contestant’s predictions and produces a signal that clears both local submission requirements.

Locked decisions

  • Use the full walk-forward throughout the search.
  • Test feature agreement across assets first. Keep the matched control and candidate identical apart from the agreement feature, including their position smoothing.
  • Submit only with positive full walk-forward net Sharpe above the shipped baseline and an unrounded nearest-city distance of at least 60° on the current Season 2 map. Hold if the novelty comparison is unavailable or falls below 60°.

First experiment

For each hour, rank each supplied feature across the 20 assets. Learn from each training split whether higher or lower ranks tend to align with the target. For each asset, weight each directional vote by its rank distance from the median, then average the signed votes. Compare the candidate with a control using the same rank inputs, learner settings, and position smoothing. Report both full walk-forward scores alongside the shipped baseline.

Alternatives considered

  • The proposed one-time holdout was set aside in favor of using the full walk-forward for every comparison.
  • Recent rank changes and turnover-only changes were deferred so the first comparison can isolate agreement.

Risks to check

  • Repeated use of the same periods can favor lucky trials. Keep a record of every result.
  • Correlated features can cast redundant votes. The matched control tests whether explicit agreement contributes beyond the ranks themselves.
  • The organizer checks time-averaged correlation for quality-set admission. The city measurement supports the local submission decision.
